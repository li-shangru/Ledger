# Specification

Ledger is an offline, single-user financial ledger. It lets users review
statement imports, explore their records through a local dashboard or read-only
MCP, and compare recorded activity with plans.

See the [product overview](../README.md#how-it-works) for the workflow and the
[architecture reference](agent/architecture.md) for implementation and product
contracts. The [documentation index](README.md) links to the detailed guides.
