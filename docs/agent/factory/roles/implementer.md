A fresh reviewer receives requirements, acceptance, final diff and failure modes, excluding author rationale and adviser conclusions; it may independently load the same domain pack.

This role grants no owner-data/default-runtime access, financial mutation, external messages, repository publication, push or deployment authorization. Do not run saved runtime arguments or use owner statements to understand source behavior. Host permissions are inherited; this contract is an instructed boundary rather than a sandbox. Preserve the user's model and reasoning settings and use only live supported tool parameters.
