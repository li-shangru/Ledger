# Reporting a security issue

Report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/li-shangru/Ledger/security/advisories/new).
Include the affected version, impact, relevant code location, and a minimal
reproduction using freshly authored synthetic data.

Do not attach financial databases, real statements, credentials, or personal
information. Do not post exploit details in public issues.

See [Security and privacy](docs/security.md) for storage boundaries, local access
controls, agent integration, and development guidance. No response time or
supported-version maintenance window is promised.
